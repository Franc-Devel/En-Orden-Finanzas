# Privacidad / Privacy

## Español

Esta presentación se creó desde cero el 10 de octubre de 2026. No contiene código, historial, registros, comprobantes, capturas, secretos, IDs de servicios ni configuración de producción del sistema privado. La única identidad publicada es la autoría pública de GitHub.

Antes de prepararla se inspeccionaron las 11 referencias disponibles y los 11 commits alcanzables; se revisaron 86 blobs únicos y 66 rutas históricas, además de metadatos de autoría. Se buscaron credenciales, tokens, claves, correos, identificadores, referencias personales, importaciones financieras y archivos sensibles. No se encontraron blobs binarios en los objetos disponibles.

Gitleaks 8.30.1 analizó el historial y los objetos locales. Cuatro alertas del historial se revisaron: tres marcadores de migración y un valor de prueba. La revisión adicional detectó referencias personales y financieras, IDs de servicios y un correo personal histórico. Todos se excluyeron mediante la creación independiente de esta presentación. Los resultados detallados permanecen fuera de este repositorio.

El alcance es el repositorio y sus objetos disponibles, no las bases, almacenamiento, secretos de alojamiento, mensajes, archivos ignorados, objetos eliminados inaccesibles ni estado de producción. Un escáner sin alertas no garantiza ausencia absoluta de secretos. La selección explícita de archivos nuevos evita trasladar contenido privado.

La demo usa datos inventados, sin red, persistencia, cuentas, formularios de carga ni servicios externos. No se despliega automáticamente este repositorio.

## English

This showcase was authored from scratch on October 10, 2026. It includes no private-system code, history, records, receipts, screenshots, secrets, service identifiers, or production configuration. The only published identity is public GitHub authorship.

The review covered 11 available refs, 11 reachable commits, 86 unique blobs, 66 historical paths, and author metadata. Checks targeted credentials, tokens, keys, email addresses, identifiers, personal references, financial imports, and sensitive files. No binary blobs were found among available objects.

Gitleaks 8.30.1 scanned history and local objects. Four history alerts were reviewed: three migration markers and one test value. Additional review found personal and financial references, service IDs, and a historical personal email. All were excluded by independently authoring this showcase. Detailed findings remain outside this repository.

Scope covers the repository and available objects, not databases, object storage, hosting secrets, messages, ignored files, inaccessible deleted objects, or production state. A clean scan does not guarantee absolute absence of secrets. Explicitly selecting new files avoids transferring private content.

The demo uses invented data and has no network access, persistence, accounts, uploads, or external services. This repository is not deployed automatically.
